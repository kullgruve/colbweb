EML Email Creator

Create a local RFC-style .eml message by entering the headers, date, body, and optional attachments.

Local file only: this tool does not send email or connect to iCloud, Gmail, Outlook, or any mail server. It only creates a file on your computer.
You can enter a historical date and time.
Example: <abc123@example.com>
For testing/archival use. Enter header lines exactly as you want them.
Attachments are embedded into the generated MIME message.
Use Preview to inspect the raw message before downloading.
